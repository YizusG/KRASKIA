# KRASKIA Creative Studio

Portafolio comercial de KRASKIA, construido con **React + Vite**.

## Desarrollo local

```bash
npm install
npm run dev
```

## Compilación para Hostinger

```bash
npm run build
```

Vite genera la carpeta `dist/`. Para publicar el sitio estático en Hostinger, copia **el contenido** de `dist/` a `public_html/` del sitio temporal `oaken-lightyellow-mink-38.hostingersite.com` (no copies `src/`, `node_modules/` ni el proyecto React sin compilar).

**Importante:** no tocar las carpetas de los sitios institucionales `sanjosedelcitara.com` ni `red.sanjosedelcitara.com`.

## Contenido pendiente antes de publicar como sitio definitivo

- Reemplazar las cuatro ilustraciones conceptuales por proyectos propios y autorizados; hoy se etiquetan como **muestras**.
- Configurar información real de contacto y un WhatsApp comercial. La interfaz indica explícitamente que el contacto está pendiente.
- Conectar videos reales de YouTube cuando exista el canal y los enlaces correspondientes.
- Confirmar disponibilidad marcaria de KRASKIA en la SIC y registrar el dominio si procede.
- Sustituir el dominio temporal de Hostinger por el dominio propio cuando se haya adquirido.

No se incluyen ni se inventan referencias de clientes, testimonios, cuentas sociales o teléfonos.

## Estructura

`src/App.jsx` contiene la interfaz y textos. `src/styles.css` contiene el sistema visual responsive. `index.html` define metadatos y tipografías.

## Identidad

Paleta carbón, naranja quemado, coral y marfil. Eslogan: **Ideas que encienden marcas**.
